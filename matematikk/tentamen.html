PYTHON

Oppgave 24

Se på Python-programmet nedenfor, som simulerer myntkast der 1 betyr kron og 2 betyr mynt:

from random import randint

antall_kast = 100
kron = 0
mynt = 0

for i in range(antall_kast):
    kast = randint(1, 2)
    if kast == 1:
        kron = kron + 1
    else:
        mynt = mynt + 1

print("Relativ frekvens kron:", kron / antall_kast)
print("Relativ frekvens mynt:", mynt / antall_kast)
  1. Forklar kort hva programmet gjør i løkka for i in range(antall_kast): og hva som skrives ut til slutt.
  2. Hva forventer du at den relative frekvensen skal bli for de to utfallene?
  3. Hvordan kan du endre programmet slik at det simulerer \(10\,000\) myntkast? Blir de relative frekvensene nærmere det du forventer nå? Forklar hvorfor.
